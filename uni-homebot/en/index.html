Community catalogue

Set up in a few minutes

A Linux server is required: Ubuntu, Debian, Fedora, Arch, or Alpine through Docker.

Create a bot

Get a token from @BotFather.

Run the command

The script installs dependencies and asks for your token.

Become the owner

Send the bot /start КОД from the installation log.

# номер версии из последнего релиза
V=10.0.0
curl -fsSL https://github.com/vkardin/uni-homebot/releases/download/v$V/homebot-$V.tar.gz | tar xz
sudo bash homebot/deploy/install.sh
# без systemd и без пакетов в системе
V=10.0.0
curl -fsSL https://github.com/vkardin/uni-homebot/releases/download/v$V/homebot-$V.tar.gz | tar xz
cd homebot && sudo bash deploy/install.sh --docker

Update from the chat (Settings → Update) or run the same server script again. Your .env and data are preserved.
